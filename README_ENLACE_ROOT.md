# Somos ENLACE — raíz del proyecto

Esta carpeta está preparada para copiarse directamente a la raíz del repositorio GitHub de ENLACE.

## Estructura principal

- `src/` — código fuente React/Vite
- `public/` — recursos públicos
- `public/proyectos/casos_exito.csv` — catálogo de proyectos
- `public/proyectos/imagenes/` — imágenes P001–P005
- `package.json` — dependencias y scripts

## No se incluyen

- `dist/` — build generado
- `.bolt/` — archivos internos de Bolt
- `node_modules/` — dependencias instaladas

## Flujo recomendado

GitHub → Vercel → somosenlace.app
